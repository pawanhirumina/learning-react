### What it is

commit-print takes your GitHub contribution history and renders it as a minimal, print-ready poster. No clutter. Just your grind.

### What it does

**- Turns your graph into art**
Fetches any GitHub profile and re-draws the contribution grid in a clean, typographic poster layout.

**- Built for print**
High-res export, perfect margins, colors that actually look good on paper. Designed for A3, A4, 12x16.

**- Light & Dark**
Two native themes. Light for paper, dark for screens.

**- Zero noise**
No dashboards. No analytics. Just your username -> poster -> print.

**Built with React + Vite + GitHub API.**
